# Bundled typefaces

The interface serves these families locally so the reading experience does not depend on a third-party font request:

- **Atkinson Hyperlegible Next** — body and interface text. Source: https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegible
- **Newsreader** — display headings. Source: https://github.com/google/fonts/tree/main/ofl/newsreader

The matching SIL Open Font License texts are included beside each WOFF2 file in this directory.
